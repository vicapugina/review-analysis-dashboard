# Анализ отзывов на товар

## 📌 Описание проекта
Проанализировала 133 отзыва пользователей на секатор с Wildberries, чтобы выявить проблемные зоны и сильные стороны продукта.  
Данные собраны с помощью парсинга, обработаны в Excel, визуализированы в DataLens.

## 🎯 Цель
- Выявить ключевые проблемы, волнующие пользователей
- Найти сильные стороны продукта
- Предложить срочные и плановые рекомендации

## 📊 Данные
- **Источник:** Wildberries (отзывы на секатор)
- **Объём:** 133 отзыва
- **Поля:** оценка, текст отзыва, дата, имя покупателя
- **Файл:** `data/reviews.xlsx`

## 🛠 Инструменты
- **Сбор данных:** готовый парсер (выгрузка в Excel)
- **Обработка и анализ:** Excel (сводные таблицы, Power Query)
- **Визуализация:** DataLens

## 📈 Дашборд
Дашборд позволяет:
- видеть распределение оценок,
- отслеживать динамику негатива по месяцам,
- фильтровать отзывы по темам (качество, размер, хрупкость).

![Дашборд](dashboard/dashboard_preview.png)

## 🔍 Ключевые выводы
1. **Сильная сторона:** покупатели ценят качество материалов и остроту лезвий
2. **Проблемная зона №1:** 8 отзывов о быстрой поломке
3. **Проблемная зона №2:** 7 отзывов о несоответствии размера (оказался меньше ожидаемого)

## 💡 Рекомендации
| Тип | Рекомендация |
|-----|--------------|
| **Срочные** | Усилить контроль качества на производстве |
| **Срочные** | Указать точные размеры в карточке товара |
| **Плановые** | Улучшить материалы, добавить видео-обзоры |

## 📂 Структура репозитория
- `data/` — файл с отзывами в Excel
- `dashboard/` — скриншот дашборда
- `insights/` — текстовые выводы
