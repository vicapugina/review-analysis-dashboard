# Анализ отзывов на кухонные весы SF-400

## 📌 Описание проекта
Проанализировала 125 отзывов пользователей на электронные кухонные весы SF-400 с Wildberries.  
Цель — выявить ключевые проблемы, сильные стороны продукта и предложить рекомендации для улучшения.

## 📊 Данные
- **Источник:** Wildberries (отзывы на товар)
- **Период:** 23 октября 2022 – настоящее время
- **Объём:** 125 отзывов
- **Методы анализа:** тональность, тематическое моделирование, NPS

## 🛠 Инструменты
- **Сбор данных:** готовый парсер (выгрузка в Excel)
- **Обработка и анализ:** Excel (сводные таблицы, Power Query)
- **Визуализация:** DataLens

## 📈 Дашборд
Дашборд позволяет:
- видеть распределение оценок,
- отслеживать ключевые темы в отзывах,
- анализировать динамику проблем и преимуществ.

## 🔍 Ключевые выводы

### ✅ Преимущества (за что хвалят)
| % | Что ценят |
|---|-----------|
| 35% | Многофункциональность |
| 25% | Дизайн и компактность |

### ⚠️ Проблемы (на что жалуются)
| % | Проблема |
|---|----------|
| 28% | Отсутствие батареек в комплекте |
| 25% | Неточные измерения |

### 📊 Индекс лояльности (NPS)
**NPS = +40%** — пользователи в целом довольны, но есть точки роста.

## 💡 Рекомендации

### 🔴 Срочные (в течение 2 недель)
1. **Обязательная комплектация батарейками** — прописать в договорах с поставщиками
2. **Выборочный контроль точности** (±1 г) при приёмке товара

### 🟡 Среднесрочные (1–2 месяца)
3. **Разработать инструкцию на русском языке**
4. **Рассмотреть расширенную гарантию**

### 🟢 Долгосрочные (3–6 месяцев)
5. **Перейти на модели с механическими кнопками** (по отзывам надёжнее)
6. **Обновить описания товара** — акцент на многофункциональность

## 💰 Экономический эффект
| Показатель | Ожидаемый рост |
|------------|----------------|
| Снижение возвратов | 15–20% |
| Увеличение конверсии | 5–7% |
| Рост среднего чека | 3–5% |
| Улучшение рейтинга на маркетплейсах | ✅ |
